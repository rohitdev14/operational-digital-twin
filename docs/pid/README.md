# P&ID — Day 1

The editable P&ID source will live in this directory once the final Day-1 drawing is exported.

The drawing must use the same persistent tag IDs as `knowledge/assets.yaml`.

## Frozen drawing principles

- Five parallel 30 kW centrifugal pump + motor + VSD packages.
- Metered makeup water with tank-level control.
- Unique tags for mechanical components and instruments.
- Differential pressure across each suction strainer.
- Pump suction/discharge pressure and vibration available to the knowledge layer.
- Non-return valve and manual maintenance isolation on each pump discharge.
- Common discharge pressure and flow measurement.
- Energy/power measurements associated with pump operation.
- Open-loop variable user demand.

The P&ID is a conceptual educational/reference drawing, not an issued-for-construction document.
